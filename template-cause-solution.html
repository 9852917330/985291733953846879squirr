4. Cause / Solution

Use for: “What are the causes of this problem and what solutions can be suggested?” / “Why is this happening and what can be done?”
Core approach: Identify the most important causes and match each solution to an actual cause or problem raised in the essay.

Introduction

Paraphrase the problem.

This issue is mainly caused by cause 1 and cause 2, and it can be addressed through solution direction.

Body Paragraph 1 — Causes

There are two main reasons why problem occurs.

First, cause 1. This leads to explain how it creates the problem.

Second, cause 2, meaning that explanation.

For example, relevant example if useful.

Body Paragraph 2 — Solutions

Several measures could address these causes.

To tackle cause 1, government / schools / employers / individuals should solution 1.

In addition, solution 2 would reduce the impact of cause 2 by explanation.

If implemented effectively, these measures could expected result.

Conclusion

In conclusion, problem largely stems from main causes, but targeted measures such as main solutions could substantially reduce it.
