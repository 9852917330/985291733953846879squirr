Writing Task 2 Template

8. Two-Part Questions

Use when the task asks two separate questions, for example: “Why is this happening? Is it a positive development?” or “What problems does this cause? Who should be responsible?”
Core approach: Answer both questions fully and in the order asked. Each body paragraph should normally have one clear job: Question 1, then Question 2.

Introduction

Paraphrase the overall topic.

This essay will argue that short answer to Question 1 and that short answer to Question 2.

Body Paragraph 1 — Answer Question 1

Regarding Question 1, direct answer.

The main reason is reason / explanation.

A further factor is second point if needed.

For example, relevant example.

Body Paragraph 2 — Answer Question 2

As for Question 2, direct answer.

This is because explanation.

In particular, develop the point / consequence / example.

Therefore, clear closing judgement for Question 2.

Conclusion

In conclusion, brief answer to Question 1, while brief answer to Question 2.
